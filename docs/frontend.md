# Frontend Development

The frontend is a modern **React 19** Single Page Application (SPA) built with **TypeScript** and **Vite**. It is designed to be fast, responsive, and visually stunning, consuming the static data generated by the backend scrapper.

## Architecture

The frontend follows a "static data, dynamic UI" architecture.

-   **Data Source**: `/public/collection.json` (Main Index), `/public/album/{slug}/`, `/public/artist/{slug}/` (Detail Data).
-   **Routing**: Client-side routing with `react-router-dom`. URL paths map directly to the slugified structure of the static data.
-   **State Management**: React Query (TanStack Query) or simple fetch hooks are used to load the static JSON files.

### Key Components

*   **`src/pages/HomePage.tsx`**: Displays the main collection grid. Implements virtualization or pagination for performance.
*   **`src/pages/AlbumDetailPage.tsx`**: Renders the rich album view, including artwork, tracklist, and editorial content.
*   **`src/pages/ArtistDetailPage.tsx`**: Shows artist biography and discography (releases present in the collection).
*   **`src/components/Navigation.tsx`**: Global navigation and search overlay.

## Development Workflow

### Application Config

Global settings like pagination limits and external URLs are found in `src/config/app.config.ts`.

### Styling

We use **Tailwind CSS** for styling, combined with **shadcn/ui** components.
-   **Theme**: Dark mode is the default aesthetic.
-   **Album Colors**: The build process extracts dominant colors from album art to create dynamic backgrounds (`generate-colors` script).

### Image Handling

**Crucial**: The system uses specific image sizes.
-   `hi-res`: 1400px (Details)
-   `medium`: 800px (Grid)
-   **Note**: There is NO `small` size. Do not use it.

Always use the utility functions in `src/lib/image-utils.ts` to generate URLs:
```typescript
import { getAlbumImageUrl } from '@/lib/image-utils';

// Correct path generation
const imgUrl = getAlbumImageUrl(albumSlug, 'medium');
```

## Build & Optimization

The build process is more than just bundling JS. It includes asset optimization steps handled by `deploy.yml`.

1.  **Image Optimization**: Converting and resizing images.
2.  **Color Extraction**: Generating `album-colors.json` for UI theming.
3.  **OG Image Generation**: Creating statically cached Open Graph images for social sharing.

To run a production build locally:

```bash
pnpm run build
pnpm run preview
```
