Services are configured via the config.json file in the scrapper directory. Each service requires specific API credentials.

Discogs

Requires: access_token, username

Apple Music

Requires: key_id, team_id, private_key_path

Spotify

Requires: client_id, client_secret

Last.fm

Requires: api_key

Perplexity

Requires: api_key (for AI-generated descriptions)

Wikipedia

No credentials required
